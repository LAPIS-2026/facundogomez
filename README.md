# Códigos y Datos para Práctico — Prof. Facundo Gómez (LAPIS 2026)

Repositorio de materiales y acceso a datos para el práctico del Profesor Facundo Gómez (*Linking morphological and kinematic distortions with galactic evolutionary histories*) en la escuela de astrofísica **XII LAPIS 2026**.

## Proyecto

- **Título**: *Galaxy morphology as a tracer of interaction history*
- Estudio de perturbaciones morfológicas y cinemáticas (alabeos/*warps* y asimetrías/*lopsidedness*) en discos galácticos usando la simulación **TNG50** de IllustrisTNG y descomposición de Fourier.

## Datos, Catálogos y Plataforma

- **Acceso a datos y JupyterLab web**: [IllustrisTNG Data Access (`https://www.tng-project.org/data/`)](https://www.tng-project.org/data/)
- **Importante**: Por favor crea una cuenta con anticipación en el sitio web de IllustrisTNG y verifica el acceso al entorno JupyterLab basado en la web antes del inicio de la escuela.
